# 🌙 LunaReads

> **A quiet place for loud stories.**

LunaReads is a modern, immersive landing page designed for book lovers who enjoy discovering stories in a calm and elegant digital environment.

The website combines a dark editorial aesthetic with warm typography, atmospheric imagery, and a simple user experience to create the feeling of stepping into a digital midnight bookstore.

## ✨ Features

* 🌙 Elegant dark-themed bookstore aesthetic
* 📚 Book-focused visual experience
* 🖼️ Atmospheric library and book imagery
* ✨ Clean and responsive layout
* 🧭 Simple navigation and call-to-action sections
* 📱 Responsive design for different screen sizes
* ⚡ Lightweight frontend with no unnecessary dependencies

## 🛠️ Built With

* **HTML5** — Page structure
* **CSS3** — Styling, layout, typography and responsive design
* **JavaScript** — Interactive functionality
* **GitHub Pages** — Deployment and hosting

## 🎨 Design Philosophy

LunaReads is designed around the idea of a **quiet digital reading space**.

The visual direction uses:

* Deep, dark backgrounds
* Warm editorial typography
* Book and library photography
* Minimal navigation
* Spacious layouts
* Atmospheric visual elements

The goal is to make the interface feel more like a **literary experience than a typical website**.

## 📱 Responsive Design

The landing page is designed to provide a consistent experience across:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet
